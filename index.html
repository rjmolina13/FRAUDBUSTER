About FraudBuster

FraudBuster is an intelligent Chrome extension that helps users identify potentially fraudulent job postings using ML-inspired scoring, rule-based pattern matching, and multiple false-positive reduction techniques.

  • Real-time page scanning with risk scoring
  • Fraud pattern detection (urgency, salary promises, suspicious comms)
  • False-positive reduction via page and content density analysis
  • Optional Firebase-backed model updates and analytics

Learn more at github.com/rjmolina13/FRAUDBUSTER
